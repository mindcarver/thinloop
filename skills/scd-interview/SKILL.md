# SCD 面试题

开始执行前必须先读取并遵守[步骤沟通](../scd-quickdev/references/step-communication.md)；直接调用本技能也适用。

把开发对话中的技术实质转化为个人学习面试题。仅在用户明确请求时运行，提取只授权分析候选题，确认精确草稿、范围和目标位置后才写入。不监控普通开发、主动提取或修改其他 Skill、规则、ADR 或 Hook（与 `scd-knowledge` 分离：本技能服务面试准备而非 Agent 决策）。

## 选择请求的操作

- **提取：** 评审最近对话提取面试题。
- **检索：** 按主题、级别或问题搜索已保存题目。

## 解析题库

个人题库根目录优先级：1. 本次明确提供的绝对路径 → 2. `<user-home>/.scd/config.json` 的 `interview_root` → 3. 默认 `<user-home>/.scd/interview-questions/`（目录含 `INDEX.md`、`questions/`、`archive/`）。运行时解析主目录不硬编码；首次提供时合并进用户级配置且保留无关键，配置 JSON 无效则报错不覆盖。

## 提取题目与检索

- **提取题目：** 聚焦带取舍决策、根因诊断、机制架构、模式、失败边界及性能/安全推理；用“为什么选 X / 失败下如何工作”等理解型问题，拒绝纯记忆、流程叙述、对话摘要、私密内容与编造答案。按 `assets/question-entry.md` 写明问题、参考答案、标签、难度与对话出处，先查 `INDEX.md` 与匹配正文去重（完全重复跳过、近重复建议编辑、冲突呈现）。展示候选题后由用户选择保留项并请求一次明确确认，确认后用小写字母/数字/连字符 slug 写入 `questions/<slug>.md` 并按 `assets/question-index.md` 更新 `INDEX.md`，报告精确变更文件（不得暂存、提交或推送）。
- **检索：** 只读无需确认。按主题/级别搜 `INDEX.md` 并只读匹配条目（除非查历史否则不读 `archive/`），返回问答，无匹配直接说明。

## 强制边界与资源

即使普通确认已给出，也绝不写入凭据、令牌、私钥、Cookie 等敏感内容（脱敏私密信息；消去意义则删题）；目标缺失/不可写时阻塞而不悄悄改写目录；保持紧凑且不默认写入项目知识库；仅答案以对话为依据时才称“已覆盖”。

- `references/interview-contract.md`：准入、答案依据、去重与安全规则。
- `assets/question-entry.md` / `assets/question-index.md`：题目与索引模板。
