# 设计品味

UIUX 设计在生成任何视觉产物前共用本参考。它负责生成侧判断：先固定方向、封死模板化默认。产物验收仍按[页面视觉质量](visual-quality.md)的八维、轮次与证据执行；二者冲突时先统一再继续。

## 生成前方向块

生成线框、视觉稿或原型前，先把五项方向决策写入 UX 契约「视觉方向与系统增量」。说不出任一项时不得开始生成；说不出方向的生成必然回落均值：

- 领域与气质：产品类别，加一个结果必须成立的一个词气质（如「克制」「精密」「温暖」）；
- 受众与语气：专家或新手、冷静或活力、高级或实用；
- 动效深度：无 / 仅反馈 / 表达性编排，三选一并说明；
- 布局族：命名的分节序列，说明每节构图如何变化，不重复同一行式；
- 参考锚点：对标的具名系统或作品，来源可核对；无法联网对标时按页面视觉质量的外部对标规则记录。

方向块先于产物存在。产物偏离方向块时，先改方向块或改产物并记录原因，不得事后解释成「风格选择」。清晰局部变更继承现有方向，只写增量。

## 反模式黑名单

以下默认每一个都是缺陷，不是起点。生成时逐条规避，自审时命中即按对应维度 `FAIL`：

| 默认 | 为什么读起来像生成物 | 替代 |
|---|---|---|
| 三个或四个等权重卡片并排 | 视线无处落 | 让一个要素领先：更大、更重或独占一行 |
| 整页居中 | 无张力、无层级 | 真实网格上的不对称；居中是刻意例外 |
| 同一「左文右图」行式重复 | 明显模板化 | 每节构图有意变化 |
| 标题只是加粗正文 | 没有显示层级 | 最大标题至少 2.5 倍正文，短，18–24 字符行长 |
| 每个盒子都有投影 | 浑浊、过时的深度 | 大部分平面；阴影稀有而分层 |
| `#000` 压 `#fff` | 刺眼、业余 | 主题内的暖白底配非纯黑文字 |
| 强调色彩虹 | 无纪律 | 一个主色，至多一个强调色；中性色承担主体 |
| emoji 当图标、项目符或状态点 | 最响的生成物痕迹 | 内联 SVG 图标用 `currentColor`，或纯文字 |
| 单侧彩色边条 | 陈词滥调的装饰 | 完整细边框或面分隔；状态用图标加文字 |
| 拥挤的垂直节奏 | 密集、焦虑 | 分节之间保留慷慨的宏观留白 |

## 文案纪律

界面文案禁用：营销填充词（「赋能」「无缝」「解锁」「极致」）、空洞三连（「强大、直观、美观」）、假结构标签（「SECTION 01」、lorem ipsum、「在此输入标题」）和过度对冲的微文案。写具体的、可验证的事；读出来像新闻稿就删短、写具体。

## 移动优先

基础样式即窄屏布局，更宽的屏幕用 `min-width` 逐层叠加。禁止桌面优先、回头再补移动端。`max-width` 属性用于阅读行长、容器上限与图片约束，不受此限制。
