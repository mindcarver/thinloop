- **设计方法论与双视角评审**：BMAD WDS（MIT）触发映射/场景/设计循环中文改写适配两阶段保真度；自写 Web 平台设计原则（引用 Apple HIG / Material 官方出处，不复制原文）；八维自审并入规范审+工作室主审双视角。
