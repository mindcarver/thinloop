# Thinloop v0.18.0

## 范围

- 新增 `scd-ui-polish`，可单独优化已有 Web 页面；修改仓库时复用 QuickDev 的 Issue、工程验证、独立验收和交付流程。
- UIUX 设计、QuickDev 页面验收和新技能共用 `skills/scd-uiux/references/visual-quality.md`。八维视觉标准只维护一份，覆盖排版、留白、层级、色彩、动效、微交互、响应式和辨识度。
- 页面修改前保存真实浏览器基线，按适用视口完成至少两轮实际自审，必要时增加第三轮；提供同条件前后对比，保留新页面、局部修改与无动效场景的合理边界。
- 目录、路由与安装说明同步为十三个 Skill；已有设计确认、最终视觉确认、真实页面与独立子智能体验收门保持有效。

## 验证与边界

- 仓库检查覆盖技能发现、共用参考可达性、源码链接与插件目录下的相对引用、版本与各平台载荷一致性。
- 缺少必需浏览器、状态或证据时保持 `BLOCKED`；外部获奖作品只在实际查看后作为参考，不承诺获奖或不存在改进空间。
- 本版本改变技能指令与流程，不代表任何具体产品页面已改善，也不代表已运行页面视觉质量的对照实验。安装更新与活动会话重新加载分别验证和报告。
