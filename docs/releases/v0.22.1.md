# Thinloop v0.22.1

QuickDev 在关键行为开工前使用 [scd-test](../../skills/scd-test/SKILL.md)，从原始要求和批准版本设计可观察的测试与关键反例。既有批准场景仍可复用。

合并前由现有独立验收者使用 scd-test 对照获批预期与完整差异并亲自验证。候选的绿测可以补充证据，观察到行为回退则保持 FAIL；必需证据缺失则保持 BLOCKED。只有当前候选的独立 PASS 和现有交付门齐备才可以合并。

十五个技能按现有安装方式刷新。隔离回放办法见 [QuickDev 与 scd-test 场景](../../evals/delivery/quickdev-scd-test-scenarios.md)。
