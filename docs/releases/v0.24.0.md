# Thinloop v0.24.0

本版本在保持 15 个规范路由技能与轻量 `SKILL.md` 布局前提下，补齐代码结构质量与外部先验工程纪律（#155）：

- **跨技能工程最佳实践契约（`skills/scd-quickdev/references/engineering-practice.md`）**：
  - **§1 架构与模块边界**：按业务变化轴高内聚拆分、依赖单向指向稳定核心并禁止循环依赖、外部载荷在边界防腐层（ACL）映射、拒绝无边界 `utils/helpers/common` 杂烩文件。
  - **§2 接口与契约工学**：边界一次解析内部可信（Parse, Don't Validate）、窄接口与显式语义（避免超过 2 个布尔参数陷阱）、机器错误语义分级、锁与事务内禁用慢网络 IO 并明确幂等策略。
  - **§3 编码实施纪律与防过工程护栏**：复用先于复制、浅嵌套与早返回、显式失败与成对资源清理、优先运行目标仓库既有静态检查；明确禁止为仅使用 1 次的逻辑强造抽象接口/工厂，严禁借重构越界修改 Issue 范围外存量代码。
  - **§4 `code-review` 6 条结构反模式门禁**：在 `scd-quickdev` 自检、`release-contract.md` 与 `scd-test/references/acceptance-audit.md` Blind-First 独立验收中并行拦截空 `catch` 吞错、规则克隆、跨层逆向或新环依赖、事务/热循环重 IO、上帝函数与死代码/多余抽象层。
- **完整项目先查 GitHub 同类方案**：`scd-research`、`scd-discovery` 与 `scd-architecture` 对全新产品/系统/重大新子系统前置 GitHub 同类开源实现检索与三级选型确认（① 直接复用集成 → ② Fork 适配 → ③ 仅借鉴设计自研），并强制核对开源许可证与供应链安全边界（清晰局部 L0/L1 改动显式免除）。
- **开发新功能优先查看最新文档**：`planning-contract.md`、`engineering-practice.md`、`scd-architecture` 与 `interface-contract.md` 对涉及外部库/SDK/框架/CLI/平台协议的新功能开发，强制执行“先核对本地锁定版本、再优先查阅对应最新官方文档或本地类型源码，离线或不可达显式标 `UNVERIFIED`、禁止凭训练记忆编造 API”。
