# Thinloop v0.20.1

`scd-uiux` 补入生成侧设计智力，新增[设计品味](../../skills/scd-uiux/references/design-taste.md)与[设计令牌](../../skills/scd-uiux/references/design-tokens.md)两份参考。生成任何视觉产物前必须先写五项方向块（领域与气质、受众与语气、动效深度、布局族、参考锚点）并逐条排查反模式黑名单；[八维检查](../../skills/scd-uiux/references/visual-quality.md)升级为具体阈值加反模式双列（正文对比 4.5:1、触控 44px、最大标题 2.5 倍正文、行长 45–75ch、4px 间距阶梯等）；重要页面默认两阶段保真度循环，低保真只决结构与层级；UX 契约模板增加设计决策日志。治理流程与状态机不变，共用文件对 `scd-ui-polish` 与 QuickDev 保持兼容。

设计判断参考 plugin87/ux-ui-agent-skills、BMAD WDS、ui-ux-pro-max、apple-design-skill、superdesign-skill 等开源技能的公开方法（MIT 许可），按本仓库语言与治理结构改写；未引入外部插件或运行时依赖。

结构检查与隔离行为场景只验证本次指令路径，不证明跨模型一致的视觉效果；实际设计质量以用户真实使用验收为准。
