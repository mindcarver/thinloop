# Thinloop v0.23.0

本版本围绕质量强化、轻量化闭环与多宿主一致性完成七项演进：

- **UI/UX 语料瘦身与检索修复（#138）**：移除未接入检索的 33 MB `data/vendor/` 死语料与 10 张非 Web 技术栈 CSV，`skills/scd-uiux` 体积降至 1.1 MB；`scripts/search.mjs` 新增高频中英设计词同义映射并优先引导英文检索关键词。
- **计划分级与 Squash Merge 兼容（#139）**：`planning-contract.md` 引入 L0/L1/L2 规模自适应分级（L0 免建 6 模板 `.scd/plans/` 与双次本地计划提交，仍须先确认具体方案与范围），兼容仅允许 Squash Merge 的消费者仓库（以合并后默认分支持久化计划与批准记录 + 已合并 PR 通过可达性检查）。
- **UI/UX 分轨品味、存量令牌与 DOM 量化探测（#140）**：`design-taste.md` 与 `visual-quality.md` 区分展示/营销型 Web 与高密度工具/工作台型 Web App；新增 Brownfield 存量令牌提取、状态切换条令牌 HTML 原型规范，以及零依赖浏览器探测脚本 `skills/scd-uiux/scripts/dom-audit.mjs`。
- **跨产物交叉就绪核对（#141）**：`scd-project` 在多上游产物存在时前置核对 PRD（`FR-*`）↔ UX（`UI-*`/状态）↔ Architecture 共享接口契约一致性，缺口通过 `blockers` 阻断 `READY` 并按责任回流。
- **Antigravity 2.0 一等平台支持（#142）**：`hooks/check-state.mjs` 原生适配 Antigravity `Stop` 协议，`platform-capabilities.json`、`verify-install.mjs`、`refresh-install.mjs` 与 `docs/installation.md` 完整覆盖装配、刷新与防重复暴露校验。
- **`scd-test` 与独立验收升级（#143）**：建立 Blind-First 先盲验后对账、`test-review` 5 条测试反模式门禁、`P0`/`P1`/`P2` 分层、`P0`/缺陷先红后绿 ATDD、5 项触发式 NFR、非 `P0` 受控 `WAIVED` 与 L0 纯文本免子 Agent 边界。
- **15 个 `SKILL.md` 指令瘦身去重（#144）**：总字节数从 119,857 B 降至 77,717 B（-35.16%），完整保留红线、指针与零退化契约验证。
